RESTful API back end untuk SIAKAD Mini, layanan akademik sederhana yang mengelola data mahasiswa, mata kuliah, dan Kartu Rencana Studi (KRS).

Ketentuan Teknis dan Model Data

1.     Menggunakan Go.

2.     Framework sesuai pada pertemuan praktikum.

3.     Database menggunakan PostgreSQL.

Buat laporan project dan diupload di repository masing-masing dengan folder UTS pada repositoy latihan fiber
